# 🌾 Sri Lanka Rice Production & Price Forecasting

## 📌 Project Overview
An analytics project to analyze historical paddy cultivation data in Sri Lanka, identify production trends across districts, and forecast future yields to assist in food security planning.

## 🛠️ Tech Stack
- **Python:** Data Cleaning, EDA, Forecasting (Pandas, Scikit-Learn)
- **SQL (SQLite):** Data Warehousing
- **Power BI:** Interactive Dashboards for District-wise Analysis

## 📂 Structure
- `data/`: Raw and Processed datasets
- `notebooks/`: Jupyter notebooks for analysis
- `dashboard/`: Power BI reports
